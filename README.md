# Python Practice

This repository contains files I created for my own Python practice and learning. I used these exercises and small projects to practice coding, understand programming concepts, and improve my skills over time.

The code reflects different stages of my learning journey. Some examples may be well written, while others may contain mistakes, incorrect syntax, incomplete solutions, or approaches that could be improved. I have kept them as a record of my progress and the things I explored along the way.

## What is included

- Python basics and syntax practice
- Object-oriented programming (OOP) small projects
- Data structures and algorithms (DSA)
- Interview preparation exercises I practiced as a beginner
- Experiments with different Python concepts

These files are personal learning exercises and are not intended to be production-ready code. The goal was to learn by writing code, making mistakes, and practicing.

If you use these examples, try writing and understanding the code yourself instead of simply copying and pasting. Practice is how we improve.
